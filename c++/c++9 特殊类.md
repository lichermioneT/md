# c++9 特殊类

 ## 1.只能在堆上创建对象

**栈对象必须自动调用析构函数，所以把析构函数私有化，就能禁止对象在栈上创建。**

```c++
#include <iostream>
using namespace std;

class HeapOnly
{
public:
    static HeapOnly* Create()
    {
        return new HeapOnly;
    }

    static void Destroy(HeapOnly* ptr)
    {
        delete ptr;
    }

    void Print()
    {
        cout << "I am HeapOnly object" << endl;
    }

    HeapOnly(const HeapOnly&) = delete;
    HeapOnly& operator=(const HeapOnly&) = delete;

private:
    HeapOnly()
    {
        cout << "HeapOnly()" << endl;
    }

    ~HeapOnly()
    {
        cout << "~HeapOnly()" << endl;
    }
};
```

```c++
int main()
{
    // 类外面不能够进行访问的。
    // HeapOnly h;
    // 错误：构造函数是 private，不能在栈上创建

    HeapOnly* p = HeapOnly::Create();

    p->Print();

    HeapOnly::Destroy(p);

    return 0;
}
```

**1.构造函数私有化。 拷贝构造和赋值构造删除了。**

**2.两个静态成员方法。得到和销毁对象的。**



## 2.只能在栈上创建对象

```c++
#include <iostream>
using namespace std;

class StackOnly
{
public:
    StackOnly()
    {
        cout << "StackOnly()" << endl;
    }

    ~StackOnly()
    {
        cout << "~StackOnly()" << endl;
    }

    void Print()
    {
        cout << "I am StackOnly object" << endl;
    }

    // 禁止单个对象在堆上创建
    static void* operator new(size_t size) = delete;
    static void operator delete(void* ptr) = delete;

    // 禁止数组对象在堆上创建
    static void* operator new[](size_t size) = delete;
    static void operator delete[](void* ptr) = delete;
};
```

```c++
int main()
{
    StackOnly s;      // 正确：栈上创建
    s.Print();

    // StackOnly* p = new StackOnly;
    // 错误：operator new 被 delete 了，不能在堆上创建

    // StackOnly* arr = new StackOnly[5];
    // 错误：operator new[] 被 delete 了，不能在堆上创建数组

    return 0;
}
```

```c++
StackOnly* p = new StackOnly;
// 底层分两步
void* mem = StackOnly::operator new(sizeof(StackOnly)); // 申请空间
new(mem) StackOnly();                                  // 调用构造函数
```



## 3.不能被拷贝

```c++
#include <iostream>
using namespace std;

class CopyBan
{
public:
    CopyBan()
    {
        cout << "CopyBan()" << endl;
    }

    ~CopyBan()
    {
        cout << "~CopyBan()" << endl;
    }

    void Print()
    {
        cout << "I am CopyBan object" << endl;
    }

    // 禁止拷贝构造
    CopyBan(const CopyBan&) = delete;

    // 禁止拷贝赋值
    CopyBan& operator=(const CopyBan&) = delete;
};
```



## 4.不能被继承

```c++
#include <iostream>
using namespace std;

class Person final
{
public:
    Person()
    {
        cout << "Person()" << endl;
    }

    ~Person()
    {
        cout << "~Person()" << endl;
    }

    void Print()
    {
        cout << "Person::Print()" << endl;
    }
};
```

```c++
class Person
{
public:
    static Person Create()
    {
        return Person();
    }

    void Print()
    {
        cout << "Person::Print()" << endl;
    }

private:
    Person()
    {
        cout << "Person()" << endl;
    }
};
```



## 5.单例模式

```c++
#include <iostream>
using namespace std;

class Singleton
{
public:
    // 提供全局访问点
    static Singleton& GetInstance()
    {
        // 静态语句，只会在第一调用的时候执行。
        static Singleton instance; // C++11 以后局部静态对象初始化是线程安全的
        return instance;
    }
    // 1. 第一次调用 GetInstance() 时创建
    // 2. 后续再调用，不会重新创建，而是返回同一个对象

    void Print()
    {
        cout << "Singleton::Print()" << endl;
    }

    // 禁止拷贝构造
    Singleton(const Singleton&) = delete;

    // 禁止拷贝赋值
    Singleton& operator=(const Singleton&) = delete;

    // 禁止移动构造
    Singleton(Singleton&&) = delete;

    // 禁止移动赋值
    Singleton& operator=(Singleton&&) = delete;

private:
    Singleton()
    {
        cout << "Singleton()" << endl;
    }

    ~Singleton()
    {
        cout << "~Singleton()" << endl;
    }
};
```

```c++
int main()
{
    Singleton& s1 = Singleton::GetInstance();
    Singleton& s2 = Singleton::GetInstance();

    s1.Print();
    s2.Print();

    cout << &s1 << endl;
    cout << &s2 << endl;

    return 0;
}
```

```
构造私有，拷贝禁用，静态接口返回唯一实例。
```
