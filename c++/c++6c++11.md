**为什么可以用{}进行初始化， 里面的构造函数有。initializer_list<T>**

| 特性           | 说明                                        |
| -------------- | ------------------------------------------- |
| 统一初始化     | 普通变量、数组、对象、容器都可以用 `{}`     |
| 更安全         | 可以防止窄化转换                            |
| 支持容器初始化 | `vector<int> v{1,2,3}`                      |
| 支持自定义类型 | 通过 `initializer_list<T>` 构造函数         |
| 有优先级问题   | `{}` 会优先匹配 `initializer_list` 构造函数 |

## 8. 默认成员函数控制

**= default;  // 显式要求编译器生成默认函数**
**= delete;   // 显式禁止某个函数被调用**

```c++
class Date
{
public:
    Date();                         // 1. 默认构造函数
    ~Date();                        // 2. 析构函数

    Date(const Date&);              // 3. 拷贝构造函数

    Date(Date&&);                   // 5. 移动构造函数 C++11
    Date& operator=(Date&&);        // 6. 移动赋值函数 C++11
};
```

## 9右值引用

### 9.1移动语义

**左值：有名字、可以取地址、表达式结束后还存在的对象。**

**常见的左值**

```c++
int a = 10;     // a 是左值
int& r = a;     // r 是左值
*p;             // 解引用结果是左值
arr[0];         // 数组元素是左值
```

**右值：临时值、没有名字、表达式结束后就要销毁的对象。**

**常见的右值**

```c++
10;
a + 1;
string("hello");
```



**右值引用**

```c++
#include <iostream>
#include <string>
using namespace std;

void func(int& x)
{
  cout<< "左值引用" <<endl;
}

void func(int&& x)
{
  cout<< "右值引用" <<endl;
}


int main()
{
// 1.创建一个右值变量，让它绑定道临时对象10上面
  int&& r = 10;
  cout<< r <<endl;
  
// 现在绑定的22上面了
  r = 22;

// r 不是“记住”临时变量，而是成为这个临时对象的一个引用，也就是这个对象的别名。
// r 本身是一个右值，可以绑定不同的右值。

  return 0;
}

```

**右值引用：是一个变量用来基类临时对象的变量。相当于扩大了临时变量的声明周期的**

```c++
#include <iostream>
#include <string>
using namespace std;

int main()
{
// 1.创建一个右值引用的变量,现在记录的临时资源是10
    int&& r = 10;

// 1.2现在记录的临时资源是20了。
    r = 20;

// 2.移动构造了
  string s("lichermionexs");
  string s2(move(s));
// 识别“即将销毁的临时对象”，把它的资源转移给新对象，从而减少深拷贝。
  cout<< "s:" << s <<endl;
  cout<< "s2:" << s2 <<endl;
  
  return 0;
}

```



### 9.2完美转发

**完美转发就是：函数模板接收到什么类型的参数，就原封不动地把它的左值/右值属性继续传给下一个函数。**

```c++
#include <iostream>
using namespace std;

void func(int& x)
{
    cout << "左值版本" << endl;
}

void func(int&& x)
{
    cout << "右值版本" << endl;
}

template<class T>
void wrapper(T&& x)
{
    func(x);
}

int main()
{
    int a = 10;

    wrapper(a);
    wrapper(10);

    return 0;
}
```



```c++
#include <iostream>
using namespace std;

void func(int& x)
{
    cout << "左值版本" << endl;
}

void func(int&& x)
{
    cout << "右值版本" << endl;
}

template<class T>
void wrapper(T&& x)
{
    func(std::forward<T>(x));
}

int main()
{
    int a = 10;

    wrapper(a);   // 左值
    wrapper(10);  // 右值

    return 0;
}
```

```
&  + &  -> &
&  + && -> &
&& + &  -> &
&& + && -> &&
```



**总结**

| 工具                 | 作用           | 特点                                           |
| -------------------- | -------------- | ---------------------------------------------- |
| `std::move(x)`       | 无条件转成右值 | 不管 x 原来是什么，都当右值                    |
| `std::forward<T>(x)` | 有条件转发     | 原来是左值就转发为左值，原来是右值就转发为右值 |





## 10. lambda表达式

**lambda 表达式就是一个可以直接写在代码里的匿名函数对象。**

```
[捕获列表](参数列表) -> 返回值类型
{
    函数体;
};
```

```c++
#include <iostream>
#include <string>
using namespace std;

int main()
{
// 1.见见猪跑
    auto add = [](int x, int y)->int 
    {
      return x + y;
    };

    cout<< add(2, 3) <<endl;

// 2.见见猪跑
  auto f = []
  {
      cout<< "hello lic" <<endl;
  };

  f();

    return 0;
}

```



**捕获数据**

```c++
#include <iostream>
#include <string>
using namespace std;

int main()
{
  int x = 10;

  auto f = [x]()->void
  {
    cout<< "x:" << x <<endl;
  };

  f();

  x = 1000;
  f();

  return 0;
}
```

**捕获进去的时候一直都是10的。**



**引用捕获**

```c++
#include <iostream>
#include <string>
using namespace std;

int main()
{
  int x = 10;

  auto f = [&x]()->void
  {
    cout<< "x:" << x <<endl;
  };
  f();

  x = 1000;
  f();

  return 0;
}
```



**mutable登场。**

```c++
#include <iostream>
#include <string>
using namespace std;

int main()
{
  int x = 10;

  auto f = [x]() mutable ->void 
  {
    x = 77777;
    cout<< "x:" << x <<endl;
  };
  
  f();

  cout<< "x:" << x <<endl;
  return 0;
}
```



**捕获方式总结**

| 捕获方式  | 含义                          |
| --------- | ----------------------------- |
| `[]`      | 不捕获任何外部变量            |
| `[x]`     | 按值捕获 x                    |
| `[&x]`    | 按引用捕获 x                  |
| `[=]`     | 默认按值捕获用到的外部变量    |
| `[&]`     | 默认按引用捕获用到的外部变量  |
| `[=, &x]` | 默认按值捕获，但 x 按引用捕获 |
| `[&, x]`  | 默认按引用捕获，但 x 按值捕获 |

### 11.1创建线程

```c++
#include <thread>

{

{
```

### 11.3 线程等待

**线程只是一个进程内部的执行流， 一方退出就是全部退出了的。 需要等待子线程的。**

```c++
#include <thread>
#include <iostream>
#include <unistd.h>
using namespace std;

void func(int x, const string& s)
{
  int n = 10;
  while(n)
  {
    cout<< "this is cpp thread:" << x << s << n-- <<endl;
  }
}

int main()
{

  thread t(func, 666, "lichermixss");
  // 这不等待，线程还没有执行完成，程序就退出了的。
  t.join(); 

  return 0;
}

```

### 11.5判断是否可以等

```c++
#include <thread>
#include <iostream>
#include <unistd.h>
using namespace std;

void func(int x, const string& s)
{
  int n = 10;
  while(n)
  {
    cout<< "this is cpp thread:" << x << s << n-- <<endl;
    sleep(1);
  }
}

int main()
{

  thread t(func, 666, "lichermixss");
  t.detach();
  
  if(t.joinable())
  {
    cout<< "线程可以等待" <<endl;
    t.join();

  }
  else 
  {
    cout<< "线程不可以等待" <<endl;
    sleep(10);
  }

  return 0;
}

```

### 11.7操作线程

| 函数                         | 作用                     |
| ---------------------------- | ------------------------ |
| `this_thread::get_id()`      | 获取当前线程 ID          |
| `this_thread::sleep_for()`   | 当前线程休眠一段时间     |
| `this_thread::sleep_until()` | 当前线程休眠到某个时间点 |
| `this_thread::yield()`       | 主动让出 CPU             |

```c++
#include <iostream>
#include <thread>
#include <chrono>
using namespace std;

void func()
{
    cout << "thread id: " << this_thread::get_id() << endl;

    this_thread::sleep_for(chrono::seconds(2));

    cout << "子线程结束" << endl;
}

int main()
{
    thread t(func);

    cout << "main id: " << this_thread::get_id() << endl;

    t.join();

    return 0;
}
```



### 11.8锁的管理

```c++
#include <iostream>
#include <thread>
#include <mutex>
using namespace std;

int count = 0;
mutex mtx;

void add()
{
    for (int i = 0; i < 100000; i++)
    {
        mtx.lock();
        count++;
        mtx.unlock();
    }
}

int main()
{
    thread t1(add);
    thread t2(add);

    t1.join();
    t2.join();

    cout << count << endl;

    return 0;
}
```
