# c++7 异常

**异常是 C++ 用来处理运行时错误的一套机制。通过 `throw` 抛出错误，通过 `try-catch` 捕获错误。**

## 1见见猪跑

```c++
#include <iostream>
using namespace std;

int Div(int x, int y)
{
  if(y == 0)
  {
    throw "divide by zero";
  }

  return x / y;
}

int main()
{
  try 
  {
    int ret = Div(10, 0);
    cout<< ret <<endl;
  }
  catch(const char* msg)
  {
    cout<< "捕获异常的信息：" << msg <<endl;
  }
  return 0;
}

```

**总结异常常用的流程**

```c++
try
{
    // 可能抛异常的代码
}
catch (异常类型 变量)
{
    // 处理异常
}
```

**异常类型**

```c++
throw 1;                         // int
throw 3.14;                      // double
throw "error";                   // const char*
throw string("error");           // string
throw runtime_error("error");    // 标准异常对象
```
