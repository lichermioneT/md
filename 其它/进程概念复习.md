### 4. fork + 变量独立性

阅读下面代码，回答问题：

```c
#include <stdio.h>
#include <unistd.h>

int g_val = 100;

int main()
{
    pid_t id = fork();
    if(id == 0)
    {
        g_val = 1;
        printf("child: g_val=%d, addr=%p\n", g_val, &g_val);
    }
    else
    {
        g_val = 2;
        printf("parent: g_val=%d, addr=%p\n", g_val, &g_val);
    }
    return 0;
}
```

请回答：

1. 父子进程打印出的 `&g_val` 为什么可能一样？

   **因为都是 一样的虚拟地址空间，创建一个子进程，会拷贝父进程的虚拟地址空间的**

2. 既然地址一样，为什么 `g_val` 的值却能不同？

   **通过页表映射的物理地址，通过写时拷贝，所以不一样的。**

3. 这里打印出来的地址是物理地址还是虚拟地址？

   **虚拟地址**

4. 这个现象说明了进程的什么特性？

   **进程具有独立性**
